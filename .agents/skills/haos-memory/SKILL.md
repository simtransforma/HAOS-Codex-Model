# Memoria

Consulte apenas as fontes disponiveis e autorizadas. Diferencie lembranca,
documento e estado verificado. Ao fechar uma tarefa, registre um procedimento
ou decisao somente se for reutilizavel, comprovado e aprovado para o destino.

Cada registro inclui data, fonte, escopo e evidencias. Nunca grave credenciais,
transcricoes brutas, dados pessoais ou dumps em memoria versionada. Nao
declare sincronizacao com servico externo sem readback.
