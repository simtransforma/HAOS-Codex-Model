# HAOS Design

Atalho selecionavel para `/haos:design`.

## Ordem de operacao

1. Carregue o contexto HAOS aplicavel, especialmente `workspace/IDENTITY.md`, requisitos do produto e evidencias visuais existentes.
2. Use a skill `impeccable` como motor de concepcao, implementacao, critica e detector de frontend.
3. Preserve o brief explicito, o design system existente e as regras de maior prioridade do Codex/HAOS. Em conflito, essa ordem vence as preferencias genericas do Impeccable.
4. Para codigo e APIs, use ${RESOURCE_ID}. Para evidencia no navegador, use Chrome DevTools MCP. Para mudanca transversal, consulte Graphify.
5. Termine com validacao desktop e mobile, acessibilidade, console/rede e uma passada limitada do detector Impeccable.
