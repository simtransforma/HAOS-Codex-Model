# Revisao de seguranca

Inspecione superficie exposta, permissoes, autenticacao, rede, logs,
dependencias e backup em modo somente leitura. Classifique achados por
impacto e evidencia. Nao confunda hipotese com vulnerabilidade confirmada.

Nao mostre credenciais ou dados pessoais. Mudanca em producao, rede, banco ou
remocao destrutiva exige baseline, rollback e aprovacao explicita para o
escopo concreto. Nunca contorne um bloqueio para concluir a auditoria.
