# Playbook 03 - Achado crítico

1. Parar a reprodução e não ampliar o acesso.
2. Preservar somente evidência mínima, redigida e com timestamp.
3. Notificar o contato de emergência pelo canal aprovado.
4. Informar ativo, impacto potencial, pré-condição e contenção sugerida sem payload perigoso em canal aberto.
5. Aguardar direção do proprietário para nova validação.
6. Apoiar contenção sem executar deploy, banco, DNS ou infraestrutura sem OK explícito.
7. Registrar decisões e cadeia de custódia.
