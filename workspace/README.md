# Contexto local opcional

Estes arquivos sao modelos vazios de contexto, nao configuracao ativa. Preencher
somente dados autorizados e necessarios, mantendo segredos fora do Git. Nao
substituem AGENTS.md nem concedem direitos de execucao.

SOUL define postura operacional; USER preferencias genericas; IDENTITY limites
da marca; TOOLS capacidades configuradas. Ausencia de dado e desconhecido,
nao convite para importar memoria privada. Instalar skill nao instala ferramenta.

workspace/runtime/state contem o [schema](runtime/state/rito.schema.json) e o
[exemplo inativo do Rito](runtime/state/rito.example.json). Nao ha estado
de producao, hook, scheduler, banco ou daemon. Copiar exemplo nao cria tarefa.
Templates de memoria ficam em [memory/templates](../memory/templates/provenance.schema.json);
manter handoffs/dumps reais
fora deste repositorio publico.
