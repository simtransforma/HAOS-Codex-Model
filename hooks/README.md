# Hooks opcionais

Nenhum hook e ativado por este modelo. Hooks dependem do runtime, versao e
politica local e podem interceptar comandos, dados e memoria. Antes de ligar
um, defina dono, evento, payload, permissao, timeout, falha fechada e testes.

Nao copie hooks de outro usuario ou ambiente: paths, segredos e bancos podem
apontar para recursos errados. Preserve os hooks gerenciados existentes e
evite gravacao duplicada de memoria.
