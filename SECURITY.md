# Security policy

Do not submit credentials, tokens, private keys, session exports, customer
data, real infrastructure addresses or production logs to this repository.

Report a suspected exposure privately to the repository maintainers. Rotate
the affected credential in its original system before editing history. A
redacted issue is appropriate only after the sensitive value is revoked.

This template does not enable hooks or external integrations. Review local
permissions, network policy and the runtime's supported hook format before
activating any of them.
